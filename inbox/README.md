# Inbox

Drop anything the director can use here:
- DYNK app screen recordings (iPhone: Control Centre → Screen Recording, AirDrop to the Mac)
- Screenshots, product photos, B-roll, founder clips
- Logos or images for a specific video

Name files so the director can guess what they are, e.g. `app-send-money.mp4`, `app-social-recovery.mov`, `cooper-talking-head-1.mov`.

Web pages don't need to go here — the director/composers screen-record public sites with Playwright (`tools/record_web.mjs`).
